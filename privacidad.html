POLITICA DE PRIVACIDAD

Quién soy

La dirección de mi página web es: https://nerediarte.github.io.

Finalidad del tratamiento de los datos

Los datos personales facilitados por los usuarios a través de los formularios de esta página web se utilizarán únicamente para:

  • Gestionar solicitudes de información o contacto.
  • Gestionar pedidos de productos personalizados o no personalizados.
  • Comunicarse con el usuario para confirmar detalles del pedido, envío o pago.

Los datos no se utilizarán para el envío de publicidad ni comunicaciones comerciales.

Datos que se recogen

Los datos personales que pueden recogerse a través de esta web son:

  • Nombre y apellidos.
  • Dirección de correo electrónico.
  • Información necesaria para la personalización del pedido.
  • Dirección de envío.

Solo se solicitarán los datos estrictamente necesarios para gestionar la solicitud o pedido.

Legitimación para el tratamiento de los datos

La base legal para el tratamiento de los datos es el consentimiento del usuario, que se otorga al enviar el formulario y aceptar la política de privacidad.

Conservación de los datos

Los datos personales se conservarán únicamente durante el tiempo necesario para gestionar la solicitud o el pedido realizado.

Posteriormente podrán mantenerse únicamente durante el tiempo necesario para cumplir con posibles obligaciones legales.

Destinatarios de los datos

Los datos personales no se cederán a terceros salvo obligación legal.

En caso de ser necesario para el envío de productos, algunos datos podrán facilitarse a empresas de transporte con el único fin de realizar la entrega del pedido.

Derechos del usuario

El usuario tiene derecho a:

  • Solicitar acceso a sus datos personales.
  • Solicitar la rectificación de datos incorrectos.
  • Solicitar la eliminación de sus datos.
  • Solicitar la limitación del tratamiento de sus datos.

Para ejercer estos derechos puede enviar una solicitud al correo electrónico indicado en esta política de privacidad.

Seguridad de los datos

El responsable del sitio web adopta las medidas razonables para proteger los datos personales de los usuarios y evitar su pérdida, uso indebido o acceso no autorizado.

Cambios en la política de privacidad

El responsable del sitio web se reserva el derecho de modificar la presente política de privacidad para adaptarla a cambios legislativos o a mejoras en el funcionamiento de la página.
